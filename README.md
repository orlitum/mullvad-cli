# mullvad-cli

Terminal UI (TUI) и фоновый Watchdog на Rust для управления пулом аккаунтов **Mullvad VPN** (поддержка произвольного числа ключей `N`), автоматического обхода лимита в 5 устройств (Slot Eviction), контроля устойчивости туннеля и настройки Multihop (`Entry -> Exit`).

## Возможности
- **Пул из N аккаунтов**: локальное хранение ключей в `~/.config/mullvad-cli/config.toml` (`0600`) с отображением занятых слотов `[X/5]` и остатка дней подписки `[Xd]`.
- **Мастер первого запуска**: при пустом конфиге открывается пошаговый экран добавления ключей и выбора параметров безопасности (`F5` для старта).
- **Анти-кик защита и Slot Eviction**:
  - При 3 выбиваниях за 5 минут ключ уходит в карантин на 10 минут, а демон переключается на следующий аккаунт (при попадании всего пула в карантин выполняется авто-сброс).
  - При заполнении `5/5` слотов на всех активных ключах автоматически отзывается самое старое устройство вне `whitelist_devices`.
  - Просроченные ключи изолируются на 60 минут без холостого цикла перелогинов.
- **Wake-Heal и удержание профиля**: автоматический `mullvad reconnect` при зависании UDP-туннеля после сна и удержание параметров (`Entry`, `Exit`, `Multihop`, `Lockdown`, `Quantum`, `DAITA`, `IPv6`) в режиме `[LOCKED]`.
- **Бенчмарк релеев и Multihop**: параллельный TCP-замер задержки всех серверов Mullvad и проверка пары `Entry -> Exit` без разрыва соединения.

## Требования
- Установленный официальный клиент Mullvad (`mullvad-daemon` + `mullvad` CLI).
- Rust toolchain (`cargo >= 1.75`) для сборки из исходников.

## Установка
```bash
git clone [https://github.com/](https://github.com/)orlitum/mullvad-cli.git
cd mullvad-cli
./install.sh --with-systemd
```

## Использование и горячие клавиши
- `mullvad-cli` — запуск интерактивного TUI.
- `mullvad-cli --watch` — запуск в фоновом режиме автовосстановления.
- `mullvad-cli --add-key <16_DIGITS> --label "Main"` — добавить ключ через CLI.
- `mullvad-cli --ping` — замерить задержку до всех серверов Mullvad.
- `mullvad-cli --test-route "ee tll" "no osl"` — проверить задержку связки `Entry -> Exit`.

| Клавиша | Действие |
|---|---|
| `1` / `2` / `3` / `Tab` | Переключение вкладок (`Аккаунты`, `Релеи & Multihop`, `Настройки`) |
| `a` / `x` / `u` | Добавить ключ / удалить ключ / обновить слоты и дни по пулу |
| `e` / `Enter` | Назначить `Entry (Hop 1)` / назначить `Exit (Hop 2)` на вкладке релеев |
| `p` / `t` | Замерить пинг всех релеев / протестировать пару `Entry -> Exit` |
| `c` / `d` / `r` | Auto-Connect (с выбиванием слота) / Disconnect / Reconnect |
| `w` | Переключить удержание профиля (`[LOCKED]` ↔ `[FREE]`) |
| `q` | Выход |
